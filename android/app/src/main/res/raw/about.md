# Yoinks {version}

Save videos and music from TikTok, YouTube, YouTube Music, Instagram, Snapchat Spotlight, X, Facebook, Reddit, SoundCloud, Vimeo, Twitch and 1,800+ other sites. Share a link to Yoinks, pick a quality, done.

No ads, no tracking, no accounts.

## Open-source software

- [yt-dlp](https://github.com/yt-dlp/yt-dlp): the download engine. Public domain (Unlicense).
- [FFmpeg](https://ffmpeg.org): audio and video processing. LGPL 2.1+ / GPL.
- [Python](https://www.python.org): runs yt-dlp. PSF License.
- [youtubedl-android](https://github.com/JunkFood02/youtubedl-android): packages yt-dlp, Python and FFmpeg for Android. GPL-3.0.
- [QuickJS](https://bellard.org/quickjs/): JavaScript runtime used by yt-dlp. MIT.
- [Jetpack Compose, AndroidX, Room, WorkManager, DataStore](https://developer.android.com/jetpack): Apache 2.0.
- [Hilt / Dagger](https://dagger.dev): Apache 2.0.
- [Kotlin and kotlinx](https://kotlinlang.org): Apache 2.0.
- [OkHttp](https://square.github.io/okhttp/): Apache 2.0.
- [Coil](https://coil-kt.github.io/coil/): Apache 2.0.
- [Jackson](https://github.com/FasterXML/jackson): Apache 2.0.

Based on [yoinks](https://github.com/pablostanley/yoinks) by Pablo Stanley (MIT).

Thanks to everyone who works on these projects.
